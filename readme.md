# YaCut — сервис укорачивания ссылок

[![Python](https://img.shields.io/badge/Python-3.7%2B-blue)](https://python.org)
[![Flask](https://img.shields.io/badge/Flask-3.0.2-lightgrey)](https://flask.palletsprojects.com/)

YaCut — это веб-сервис для сокращения длинных URL-адресов.  
Пользователь может предложить собственный короткий идентификатор или получить автоматически сгенерированный.  
Дополнительная возможность — асинхронная загрузка файлов на Яндекс.Диск с созданием коротких ссылок для их скачивания.

## Структура проекта
```text
yacut/
├── run.py                         # точка входа в приложение
├── requirements.txt               # зависимости проекта
├── .env.example                   # шаблон переменных окружения
├── pytest.ini                     # конфигурация pytest
├── openapi.yml                    # спецификация API (OpenAPI 3.0)
├── yacut/                         # основной пакет приложения
│   ├── __init__.py                # инициализация Flask, БД и миграций
│   ├── settings.py                # настройки приложения (Config)
│   ├── constants.py               # константы проекта
│   ├── models.py                  # модель URLMap (микро-ORM)
│   ├── forms.py                   # формы Flask-WTF
│   ├── views.py                   # обработчики веб-страниц
│   ├── api_views.py               # обработчики API
│   ├── error_handlers.py          # обработчики ошибок (404, 500, InvalidAPIUsage)
│   ├── disk.py                    # асинхронная работа с Яндекс.Диском
│   ├── templates/                 # Jinja2-шаблоны
│   │   ├── base.html              # базовый шаблон
│   │   ├── index.html             # главная страница (создание короткой ссылки)
│   │   ├── download_files.html    # страница загрузки файлов
│   │   ├── 404.html               # страница ошибки 404
│   │   └── 500.html               # страница ошибки 500
│   └── static/                    # статические файлы
└── tests/                         # тесты pytest
```

## Возможности

- **Сокращение ссылок**  
  - Генерация короткого идентификатора (6 символов) или использование пользовательского варианта (до 16 символов).  
  - Валидация уникальности и допустимых символов.  
  - Мгновенное отображение готовой короткой ссылки.

- **Загрузка файлов на Яндекс.Диск**  
  - Асинхронная загрузка нескольких файлов одновременно через `aiohttp`.  
  - Автоматическая генерация короткой ссылки для каждого загруженного файла.  
  - Промежуточная страница скачивания, обходящая ограничения CORS и Referrer.

- **REST API**  
  - Создание короткой ссылки: `POST /api/id/`  
  - Получение оригинальной ссылки: `GET /api/id/{short_id}/`  
  - Подробная спецификация в формате OpenAPI (файл `openapi.yml`).

- **Пользовательский интерфейс**  
  - Две страницы: главная (создание ссылок) и `/files` (загрузка файлов).  
  - Flash-уведомления об успехе и ошибках.  
  - Адаптивная вёрстка на Bootstrap.

## Технологии

- **Backend**: Python 3.7+, Flask 3.0.2, SQLAlchemy (SQLite для разработки)
- **Асинхронность**: aiohttp (запросы к API Яндекс.Диска)
- **Формы**: Flask-WTF, WTForms
- **Миграции**: Flask-Migrate
- **Тестирование**: pytest

## Установка и запуск

### Предварительные требования

- Python 3.7 или выше
- [Poetry](https://python-poetry.org/) или `pip` + виртуальное окружение
- Токен Яндекс.Диска (см. [Получение токена](#-получение-токена-яндексдиска))

### Переменные окружения
Пример заполненного .env можно посмотреть в файле .env.example.

### Файл .env должен содержать следующие ключи:
Переменная -> Описание (пример значения)

- FLASK_APP -> Точка входа Flask (run.py)
- FLASK_ENV -> Режим работы (development / production)
- SECRET_KEY -> Секретный ключ Flask (your-very-secret-key)
- DATABASE_URI -> URI подключения к базе данных, SQLite по умолчанию (sqlite:///db.sqlite3)
- DISK_TOKEN -> OAuth-токен Яндекс.Диска (y0_AgAAAA...)

### Локальная разработка

1. **Клонируйте репозиторий**

    ```bash
    git clone git@github.com:DariaBarashkina/async-yacut.git
    cd async-yacut
    ```

2. **Создайте и активируйте виртуальное окружение**

    ```bash
    python -m venv venv
    source venv/bin/activate      # Linux/macOS
    venv\Scripts\activate         # Windows
    ```

3. **Установите зависимости**
Настройте переменные окружения

    ```bash
    pip install -r requirements.txt
    ```

4. **Скопируйте файл-шаблон и заполните его своими значениями:**
Отредактируйте .env, обязательно указав DISK_TOKEN (токен Яндекс.Диска) и SECRET_KEY.

    ```bash
    cp .env.example .env
    ```

5. **Примените миграции базы данных (или создайте таблицы автоматически)**
Если миграции не настроены, таблицы создадутся при первом запуске приложения.

    ```bash
    flask db upgrade
    ```

6. **Запустите сервер разработки**

    ```bash
    flask run
    ```
Откройте браузер и перейдите по [адресу](http://127.0.0.1:5000).
